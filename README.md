# Ramteja Portfolio (Vite + Tailwind)

## Quick start
1. Install dependencies
```
npm install
```
2. Run locally
```
npm run dev
```
3. Build
```
npm run build
```
4. Deploy to GitHub Pages (ensure repo `ramteja-portfolio` exists under your GitHub account and you've set remote)
```
npm run deploy
```

Notes:
- Tailwind is configured. If you need to change the repo name, update `vite.config.js` base property.
- Your photo is in `public/photo.jpg`. Replace it to change the image.
